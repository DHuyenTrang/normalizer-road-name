# Changelog

All notable changes to this project are documented in this file. The project
follows Semantic Versioning; changes to the bundled rule set are treated as
observable behavior changes.

## [0.1.0] - Unreleased

### Added

- Public `Mode` and `normalize` API.
- Nineteen versioned Vietnamese road-prefix rules for abbreviation and removal.
- NFC-aware, case-insensitive matching with attached road-code normalization.
- Business fixtures, Unicode tests, property tests, and generated API docs.
